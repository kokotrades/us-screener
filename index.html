Visual Setup Guide: Google Sites + Nightly US EOD

Follow these 4 visual steps once (takes 3 minutes). After this, your website updates automatically every night!

1

Create a Free GitHub Folder

Go to github.com and sign in (or create a free account).

  • Click the + icon at the top-right → New repository.
  • Type the name: us-screener
  • Leave it set to Public and click the green Create repository button.

Turn On Nightly Automatic EOD Updates

  1. On your GitHub repo page, click Add file → Create new file.
  2. Click and paste it into the "Name your file..." box (.github/workflows/daily_eod.yml).
  3. Click and paste it into the big editor box below it, then click Commit changes.

4

Get Your Live Link & Paste into Google Sites

  • In GitHub, click Settings (top tab) → Pages (left sidebar).
  • Under Branch, change None to main and click Save. GitHub gives you a live link like https://yourname.github.io/us-screener/
  • Open Google Sites → click Insert → Embed → By URL → paste that link → click Publish!
